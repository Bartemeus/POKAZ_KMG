# Windows-пакет показа

В GitHub откройте **Actions → Сборка Windows-пакета → последний успешный запуск → Artifacts**.

- **POKAZ_KMG_Setup**: скачайте архив GitHub, извлеките `POKAZ_KMG_Setup.exe`, запустите. Установка в профиль пользователя создаёт ярлык в меню «Пуск» и по выбору на рабочем столе.
- **POKAZ_KMG_Portable**: скачайте архив GitHub, извлеките из него `POKAZ_KMG_Portable.zip`, распакуйте пакет целиком и дважды нажмите `Запуск показа.cmd`.

Требуется установленный Google Chrome. Запуск работает локально без интернета. Файлы видео и 3D должны лежать рядом со страницами в исходной структуре папок. При первом показе проверьте звук, видео и 3D на целевом компьютере.

Пакеты собираются в GitHub Actions при обновлении ветки `installer/windows`, ручном запуске workflow на основной ветке и при создании тега `v*`. Артефакты доступны 30 дней. Установщик не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.
